## Comment remplir

Chaque texte se présente comme ceci :

> **Titre principal**
> - Actuel : Le secret est dans
> - Nouveau :

👉 **Écrivez votre nouveau texte après « Nouveau : »**.
👉 Si le texte actuel vous convient, **laissez « Nouveau : » vide**.

## Quelques règles

- **Longueur** : essayez de garder une longueur proche du texte actuel, surtout pour les titres et les boutons (sinon la mise en page peut casser).
- **Mots en gras** dans un titre (ex. : « Là où les **moments** gourmands prennent vie ») : ce sont les mots mis en valeur avec un style spécial sur le site. Gardez un mot (ou un petit groupe de mots) en gras dans votre nouvelle version.
- **Listes** (ex. paragraphes de la FAQ) : vous pouvez ajouter ou retirer des lignes.
- Les petites lignes cachées `<!-- ... -->` sont des repères pour le développeur : **ne pas les supprimer**.
- **Titre SEO / Description SEO** : c'est le texte qui apparaît dans Google et dans l'onglet du navigateur. Titre : ~60 caractères max. Description : ~155 caractères max.

Le site est aussi en anglais, allemand et néerlandais : il suffit de remplir la version **française**, les traductions seront faites ensuite.
